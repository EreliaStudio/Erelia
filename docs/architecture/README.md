# Architecture

Store **owner-approved cross-cutting architectural decisions** here. Decisions local to a Story belong with its technical design and decision history in that Story.

No old v1 architecture is silently carried into v2. Technical baseline proposals (Core/Client/Server boundaries, graphical Client, Server Router, RemoteNode, Sparkle integration, platform and test jobs) must be re-evaluated and approved during M1; this index is **not** an architecture approval.

Favor minimal responsibility boundaries over speculative safeguards and complexity. See [governance](../project/governance.md).
