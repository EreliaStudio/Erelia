# Architecture

Store **owner-approved cross-cutting architectural decisions** here. Decisions local to a Story belong with its technical design and decision history in that Story.

Technical baseline proposals (Core/Client/Server boundaries, graphical Client, Server Router, RemoteNode, Sparkle integration, supported platforms and test jobs) require owner-approved design during M1. This index is **not** itself an architecture approval.

Favor minimal responsibility boundaries over speculative safeguards and complexity. See [governance](../project/governance.md).
