# EP-001 Tickets

Implementation tickets for EP-001 live in this folder and use names such as:

`ST-001-YY-<implementation-goal>.md`

No ST-001 ticket is Ready yet.

The Epic is intentionally blocked on the voxel/network contracts tracked as Q-021 and Q-035 through Q-039, plus the visual-validation policy questions Q-029 through Q-031. Tickets should be created only when their owned public behavior can satisfy the Definition of Ready.

The expected near-term implementation slices are:

- shared Chunk/voxel representation;
- deterministic basic Server Chunk generation;
- initial Client/Server connection and Chunk protocol;
- Client Chunk request/cache coordination;
- Client terrain meshing;
- Client terrain rendering;
- temporary free-flight inspection controls;
- end-to-end adjacent-Chunk visual/integration validation.

These are planning slices, not yet approved Ready tickets.
