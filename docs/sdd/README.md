# Software Development Document (SDD)

The SDD records **only owner-approved** observable Erelia software guarantees, including functional and verifiable product nonfunctional requirements. Detailed requirements are introduced progressively after owner decisions, with permanent, domain-specific IDs (e.g. `SDD-NET-001`). Proposed requirements do not belong in authoritative tables.

## Domain catalog

No SDD domains or prefixes are approved yet. The owner must approve each domain name and prefix before its first requirement.

## GDD coverage map

A high-level map of **all significant GDD features** to SDD families must be prepared and owner-approved before major gameplay implementation. This index will then link each feature group to its family, including families lacking detailed requirements. This mapping is **not** an implementation-completeness report.

## Requirement table convention

Each family contains the approved requirement ID, name, verifiable guarantee, and generated Story/Test columns. The generator, validation and CI enforcement are early M1 work; no automatically generated links are claimed yet.
